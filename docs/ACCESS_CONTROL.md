# 访问控制迁移

当前站点的访问密码在 `assets/js/app.js` 中由浏览器校验。它只能遮挡页面，不能限制对 `data/`、`articles/` 和静态资源的直接请求。GitHub 仓库 `haozic/paper` 当前为公开仓库，仓库内文章也可以绕过网站访问门直接读取。

如果本站确实只允许指定读者使用，需要在发布前完成以下操作：

1. 在 GitHub 仓库设置中评估改为 Private，并确认 Cloudflare Pages 的 GitHub 集成仍有读取该仓库的权限。已公开过的提交可能已被复制，改为 Private 不能撤回既有副本。
2. 在 Cloudflare Zero Trust 中为 `paper.zhouhao.cn` 创建 Access 自托管应用，只允许指定读者身份访问。保护范围需包含根路径和 `data/`、`articles/`、`assets/`，并检查 `*.pages.dev` 预览地址没有绕开限制。
3. 用未登录的浏览器分别请求首页、一份 `data/<刊物>/meta.json`、一篇 `articles/` 正文和一个 Pages 预览地址。确认全部被服务端阻止；登录后再验证四刊阅读、搜索、离线能力。服务工作线程缓存和已保存的离线正文不会因为服务端访问规则自动从旧设备清除。
4. 通过上述验收后，再移除前端密码门和公开脚本中的密码校验。若需要撤销旧密码，请在新访问控制生效后轮换；不要再把新凭据写入仓库。

Cloudflare Access 需要站点所有者在 Cloudflare 控制台配置访问规则；本仓库不能代替该配置。仅添加 Pages 中间件但未配置服务端密钥会让网站无法访问，因此不在本次代码变更中启用未经验证的拦截。
