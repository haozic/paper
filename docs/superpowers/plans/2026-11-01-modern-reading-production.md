# 正式站点现代阅读界面

## 目标

把已确认的 demo 视觉和交互用于正式三刊网站，沿用真实目录、检索、收藏、相关阅读、阅读设置、离线缓存与访问门。

## 文件职责

- `index.html`：首页封面、搜索入口、杂志封面容器与 SVG 图标定义。
- `assets/js/app.js`：杂志封面切换、文章底栏三个图标的实际导航。
- `assets/css/modern.css`：首页、杂志、正文、搜索及移动端的最终视觉层。
- `sw.js`：新 CSS 加入离线外壳，更新资源版本。
- `HANDOFF.md`：记录本轮进展和限制。

## 实施与检查

1. 首页：用现有三张封面图替换合成封面，保留 `data/counts.json` 动态计数；右上角打开真实跨刊标题搜索；三个专题维持小尺寸。检查完整封面与手机布局。
2. 杂志：保留现有目录、板块、收藏和搜索逻辑；桌面显示当前刊物封面与目录索引，手机直接进入目录；统一轻透控件、卡片和间距。检查三刊切换、年份与期次展开、搜索入口。
3. 正文：用真实 `renderArticleFooter()` 生成纯图标底栏；保留目录、阅读设置、下一篇、右下角返回顶部及导航、文末相关阅读。检查点击与无障碍名称。
4. 发布：验证 HTML/CSS/JS、资源路径和 Service Worker 外壳，进行桌面与手机视觉检查；更新交接文档，提交并推送 `main`，核对远端提交号。

正式站点访问门保持原样。受环境限制时用隔离的本地视觉夹具检查排版，并明确记录未完成的真实页面验收。
